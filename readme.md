# Кофейный интернет-магазин

## Описание проекта

Фронтенд веб-приложения для онлайн-продажи кофе. Система позволяет покупателям просматривать каталог сортов кофе, искать товары по названию, добавлять их в корзину, выбирать способ и дату доставки, оформлять заказы и отслеживать их статус доставки.

## Основные функции

- **Каталог**: просмотр всех сортов кофе с изображением, рейтингом, количеством отзывов и ценой.
- **Поиск**: фильтрация товаров по поисковому запросу с синхронизацией через URL-параметры.
- **Корзина**: добавление товаров с выбором количества, изменение количества, удаление позиций.
- **Оформление заказа**: выбор варианта доставки с разными сроками и стоимостью, просмотр итоговой суммы, оформление заказа.
- **Заказы**: просмотр истории заказов с деталями по каждому товару, возможностью повторной покупки, переходом к отслеживанию.
- **Отслеживание доставки**: визуализация прогресса доставки по этапам.

## Технологический стек

React 19, TypeScript, Redux Toolkit, React Router, Vite

## Локальный запуск

### Предварительные требования

- Установленные Node.js (v20+) и npm
- Git

### Инструкция

1. Клонировать репозиторий

   ```
   git clone https://github.com/Nizrum/ecommerce-project-react.git
   cd ecommerce-project-react
   ```

2. Установить зависимости

   Frontend:

   ```
   cd frontend
   npm install
   ```

   Backend (в отдельном терминале):

   ```
   cd backend
   npm install
   ```

3. Запустить backend

   ```
   cd backend
   npm start
   ```

4. Запустить frontend (в отдельном терминале)

   ```
   cd frontend
   npm run dev
   ```

   Frontend будет доступен на http://localhost:5173
